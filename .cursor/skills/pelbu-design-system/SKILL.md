# Pelbu design system

From `docs/PLATFORM.md`:

- UI kit: Tailwind + shadcn/ui + Framer Motion.
- Desk palette: **Sky & Citrus**. Public: **Himalayan Dusk**, photography-led.
- Public `/book` = Airbnb-clarity funnel; desk ERP = Cloudbeds/Mews-style timeline.
- Mobile: footer tabs, not hamburger-first.
- Avoid generic purple gradients, cream+terracotta AI defaults, and dense broadsheet layouts unless a template explicitly requires them.
- Prefer real product/place imagery over abstract decoration as the main visual idea.
- Motion: intentional hierarchy (2–3 purposeful motions), not noise.
