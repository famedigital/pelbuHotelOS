# Pelbu design system

## Priority

1. UX (task success: book, order, enquire)
2. UI structure (grid, gaps, hierarchy)
3. Visual polish

## Tokens (Olakha Cedar — public only)

- Spacing: 4, 8, 12, 16, 24, 32, 48, 64, 96
- Content max width: 1120–1200px
- Touch min: 44px
- Colors: mist `#f2f4f3` bg, cedar-ink `#121a17`, juniper `#1f4d40` primary, ember `#c45c26` CTA, forest `#0e1613` bands, celadon wash
- Type: Cormorant Garamond (display) + Outfit (UI/body)
- Layout: centered brand header, full-bleed mega, mist/forest band rhythm
- **Retired for Pelbu public:** Sky/Citrus/Mint (licensed-out skin) — do not revive
- Avoid: purple gradients, Inter/Roboto defaults, card-soup heroes, pill-stat clutter
- ERP `.erp` keeps its own Sky & Citrus desk tokens — leave alone
