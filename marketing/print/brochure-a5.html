Print-house brief · A5 brochure

  • Trim: A5 portrait 148 × 210 mm. Add 3 mm bleed on all sides when imposing; keep type inside the inner frame already drawn.
  • Pages: Page 1 = rates (cream). Page 2 = experiences (dark). Duplex print · flip on short edge for correct back orientation, or hand the pair as singles.
  • Stock: 250–300 gsm matte / soft-touch (rates side readable); silk for photos. Optional soft-touch laminate on dark back only.
  • Photos: Delivered via Cloudinary at print-friendly compression — for offset/offset+digital high-run, ask design to export 300 dpi PDF/X-1a after InDesign reflow if needed.
  • PDF export: Chrome → Print → Save as PDF → paper size A5 · margins none · background graphics on.
